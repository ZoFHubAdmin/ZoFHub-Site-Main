AGPL-3.0 §13 — network-use source offer

Because ZoFHub serves the AGPL-3.0 components above over a network, their users are offered the corresponding source: it is each project's upstream repository (linked above) at the version pinned in the site's package-lock.json. To request the source for a specific deployed build, contact us at {{CONTACT}} or via the ZoFHub Discord linked in the footer below.

Two of these are modified, as AGPL-3.0 §5 requires us to state. GUST (changed 2026-07-30) has its default Wisp server repointed to this site's own same-origin /wisp/ endpoint instead of the upstream public one, so proxy traffic never leaves this domain, and carries ZoFHub's shared cloak system for parity with the rest of the site. AnuraOS (changed 2026-09-20) is served with a wisp-url added to its config.json defaults, pointing at this deployment's own tunnel — upstream ships none, so the app would otherwise have no working tunnel; no other file is altered. The corresponding source for both is linked from /licenses. Every other component above is served unmodified.

The live, machine-checked version of this offer is at /licenses (JSON: /licenses.json). That page is generated from the packages this server is actually running, so the versions it lists can never drift from the code being served, and it links the verbatim license text for every component.

This offer covers Ultraviolet, Scramjet, GUST, Wisp, Epoxy transport and libcurl transport, and it extends to libcurl.js under LGPL-3.0. GUST is modified by ZoFHub; its changes, their date, and a link to the running modified source are listed on /licenses as AGPL-3.0 §5 requires. Note on Ultraviolet and Scramjet: their npm packages declare "license": "MIT" in package.json, but both ship a full GNU AGPL-3.0 text in their LICENSE file, and GitHub reports Ultraviolet's repository as AGPL-3.0. Where those two disagree the LICENSE file is the operative grant, so ZoFHub treats both as AGPL-3.0 and makes the §13 source offer for them. This page previously listed them as MIT; that was incorrect and has been corrected.

MASQR. ZoFHub ships no Masqr code either. The MASQR project (© Mercury Workshop 2024, AntiSkip License — MIT's text plus an added condition, so not MIT) named a problem this site has: a mirror domain dies once a shared link reaches a filter vendor whose crawler fetches it and classifies it as a proxy. ZoFHub's own implementation of that idea lives in lib/masqr.mjs, is written from scratch, and is off by default. Details in docs/proxy/MASQR.md.

InvisiProxy. ZoFHub ships no InvisiProxy code — no copy, no dependency, no bundled build. Reviewing it did change two things here, both written from scratch against different libraries: ZoFHub's Wisp tunnel now states its egress rules explicitly instead of inheriting them from a library default, and there is now a check that every proxy engine really renders pages. Credit for those ideas belongs to InvisiProxy and its contributors — © TitaniumNetwork and the InvisiProxy contributors, led by QuiteAFancyEmerald. The full provenance record, including what was deliberately not taken and why, is in docs/proxy/INVISIPROXY.md and data/invisiproxy-upstream.json.

Games

The games on ZoFHub are embedded through their publishers' official / authorized embed URLs and remain the property of their respective owners. ZoFHub hosts no pirated game assets. The publishers we currently embed are GameMonetize, Y8, OnlineGames.io and GameDistribution. Famobi, HTMLGames, GameFlare and Gamezop were previously listed here and are no longer served — every one of their games is hidden at serve time. If you are a rights holder and want a game removed, see our DMCA / Copyright page.

Suroi (free software, self-hosted)

Suroi is an open-source 2D battle royale by HasangerGames, licensed GPL-3.0. It is not embedded from suroi.io — the GPL licenses you to run your own copy of the software, not to frame the developers' live site, and ZoFHub previously did the latter. That embed has been removed.

If ZoFHub is serving a self-hosted Suroi instance, the client you receive is GPL-3.0 software and you are entitled to its complete corresponding source. It is built unmodified from commit 85df5067b19a876cac4304232cc1e68ff1b07c7f of github.com/HasangerGames/suroi, which is where that source is available, as GPL-3.0 §6(d) permits. Should ZoFHub ever modify Suroi, the modified source will be published and linked here, marked as changed and dated, as §5 requires. Suroi runs as a separate program reached over the network; that is mere aggregation under §5 and does not place the rest of ZoFHub under the GPL.
